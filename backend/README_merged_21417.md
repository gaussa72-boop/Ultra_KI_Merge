# IONOS ULTIMATE AI MASTER

Modulare Python/Flask-Plattform mit IONOS AI, Meta-KI, Mirror AI, Storyteller AI,
symbolischer Quantum-Simulation, Quantum-Light/Singularity-UI, Speech-UI und Parfum-Webshop.

## Start
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python run.py
```
Öffnen: http://127.0.0.1:5001

Ohne OPENAI_API_KEY läuft der Chat im Demo-Fallback.
API-Schlüssel niemals in GitHub committen.
